# Steps-Till-Dawn
<img width="2240" height="1400" alt="Main page" src="https://github.com/user-attachments/assets/b38ef325-337e-4469-a3dd-71a4943165a1" />

This is a 2D pixel RPG game about love, lost, and letting go.  

You may see:  
- Narrative-driven gameplay with 5 endings. 
- Time rewind mechanic. 
- Pixel-level collision detection. 
- Save system with 3 slots. 
- Interactive objects and dialogue choices. 
in this game.
  
In this story, you need to find a way to bring your closest person back to life. But every step of you may affect your fate, and Every decision you choose may lead to a completely different ending.

## How to Run
～～use your leg～～

Download and install Python 3.10+ from [python.org](https://www.python.org/downloads/).
Windows users: check **"Add Python to PATH"** during installation.

Click the green **`Code`** button → **`Download ZIP`** → unzip it.

Open Terminal (macOS) or Command Prompt (Windows) and run:
`pip install pygame`  
or  
`pip3 install pygame` if it doesn't work. 

In the Terminal, navigate to the folder where you unzipped the game. For example:  
`cd Downloads/Steps-Till-Dawn-main`  

Then run:
`python main.py`  
or  
`python3 main.py  

Have fun :D

## Game Control
- `arrows` : Move
- `SPACE`: Interact/ continue
- `Esc`: Quit game
- `i`: Open inventory
- `s`: Save
